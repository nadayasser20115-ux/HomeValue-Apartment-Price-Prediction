## HomeValue – Apartment Price Prediction



#### **Project Description**



HomeValue is a simple Machine Learning project for predicting apartment prices based on:



\* Area (sqm)

\* Neighborhood

\* Number of Bedrooms



#### **How to Run**



1\. Open `HomeValue\_Apartment\_Price\_Prediction.ipynb` using Google Colab.

2\. Upload `apartment\_data.xlsx` to the Colab environment.

3\. Run all cells from top to bottom.

4\. The notebook will preprocess the data, train the model, generate predictions, and evaluate the model.

5\. To test a new apartment, enter its area, neighborhood, and number of bedrooms.



#### **Model**



The project uses Linear Regression with preprocessing techniques:



\* Target Encoding for Neighborhood

\* Standard Scaling for numerical features



#### **Evaluation**



The model is evaluated using:



\* Mean Absolute Error (MAE)

\* R² Score



The model achieved an R² score of approximately 97.25% on the test dataset.
